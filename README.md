# Social Media Image Resizer

[Use the free tool](https://hellofuturetechnologies.github.io/social-media-image-resizer/)

Choose an image, select a preset or enter custom dimensions, then download the result. **Load example** lets you try it without a file.

- Presets cover square and portrait posts, stories, landscape thumbnails, and link previews.
- Center crop fills the requested dimensions. Fit keeps the entire image and pads the remaining space.
- Export PNG, JPEG, or WebP where supported. JPEG padding is white.
- Accepts PNG, JPEG, and WebP up to 20 MiB, with output dimensions from 1 to 4096 pixels per side.

Images stay in your browser. Open `index.html` to run a local copy without dependencies.
